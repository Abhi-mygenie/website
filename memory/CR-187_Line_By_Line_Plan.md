## 1. Problem Statement

Every solution page title is generated by `SectorPage.jsx:62`:
```js
const seoTitle = `${s.name} POS System & Billing Software | MyGenie`;
```

Both keywords appear in every title tag. Neither appears in the body on **any** of the 8 pages.
Google Ads Quality Score requires keyword consistency: **ad → title → body**.
The title/body mismatch hurts Ad Relevance and raises CPC on all solution page campaigns.

## 2. Impact Analysis

### 2.1 Architecture — what drives solution page body content

All body content for the 8 solution pages comes exclusively from one file:
**`/app/frontend/src/data/sectors.js`**

`SectorPage.jsx` is a pure template. The only keyword-bearing text it contributes is `seoTitle` (meta title only — never rendered in the body). Every heading, subtitle, pain, solution card, proof quote, and FAQ on the page comes from `sectors.js`.

The `h1` field is rendered once, at the top of the hero section:
```jsx
// SectorPage.jsx:94
<h1 ...>
  <EditableText id={`${docKey}.hero.h1`} fallback={doc.hero.h1} block />
</h1>
```

## 6. Verification Gate (run after build)

python3 << 'EOF'
import os, re

pages = [
    'restaurants','cafes','qsr','cloud-kitchens',
    'hotels-resorts','food-courts','canteens','chains'
]
base = '/app/frontend/build/solutions'
all_pass = True

print(f"{'Page':<22} {'billing_sw':>10} {'pos_sys':>8}  {'meta_desc_len':>14}  Result")
print('-' * 70)
for slug in pages:
    path = f'{base}/{slug}/index.html'
    html  = open(path).read()
    body  = html[html.lower().find('<body'):].lower()
    bs    = body.count('billing software')
    ps    = body.count('pos system')
    # meta description (sub field - must still be ≤160ch)
    m = re.search(r'<meta name="description" content="(.*?)"', html)
    desc_len = len(m.group(1).replace('&amp;','&')) if m else 0
    ok = bs >= 1 and ps >= 1 and desc_len <= 160
    if not ok: all_pass = False
    flag = '✅' if ok else '❌'
    print(f'{slug:<22} {bs:>5}      {ps:>4}        {desc_len:>9}ch  {flag}')

print()
print('OVERALL:', 'PASS ✅' if all_pass else 'FAIL ❌')
EOF
