## 5. Baseline Findings (ranked)

### B-1 · P0 SECURITY · `GET /api/demo-requests` is public on production
`server.py` L575 has **no auth dependency**. `curl https://www.mygenie.online/api/demo-requests` returns HTTP 200 with **332 KB of lead PII** (names, phones, emails, business details). All other dashboard endpoints use `cms_auth.get_dashboard_admin`; this one was missed. The 2026-09-11 filter fix (CR-265) touched this exact function and did not catch it.
→ Registered as **CR-266** (INTAKE). **No fix applied** — awaits owner approval per governance. Recommend fast-track.

### B-2 · P1 DRIFT · WhatsApp toggle not persisted
Owner decided "disable WhatsApp FAB" (2026-09-11, CR-249). The zip was built with `REACT_APP_WHATSAPP_ENABLED=false`, but `frontend/.env` in the pod **no longer contains that key** (env reset on fork). The next `yarn build` will silently **re-enable** the FAB. Production has never received the disabled build (B-3).

### B-3 · P1 RELEASE · Production ≠ delivered build
Production serves `main.b23cd364.js`; the zip delivered on 2026-09-11 is `main.8907c40f.js`; preview is `main.e9f67272.js`. No record exists of *which* register CRs are in *which* hash. Release traceability is currently zero.

### B-4 · P0 FUNCTIONAL · CRM sync silently off
`FRESHSALES_API_KEY` / `FRESHSALES_BASE_URL` absent → every lead lands in Mongo only. 26 leads have no CRM id. (Known; owner-side. Tracked under existing Freshsales CRs + backfill CR-48.)

### B-5 · P0 FUNCTIONAL · `/leads` 404 on production
Confirmed again 2026-09-13 (`HTTP 404`). Nginx `try_files … =404` must become `… /index.html`. Fixed config already drafted at `/app/memory/mygenie_nginx_fixed.conf`. Owner-side.

### B-6 · P1 PROCESS · Untracked code change
`server.py` L577–578 probe filter (2026-09-11) shipped with no CR, IA, plan, or approval. **Retro-registered as CR-265** with a short IA (`/app/memory/CR-265_DemoRequests_500_Probe_Filter.md`).

### B-7 · P1 PROCESS · Register is not a single source of truth
The register contains batch tables **plus** several "roll-up" tables; 19 CRs carry contradictory statuses (e.g. CR-264 is ✅ CLOSED in one table and 📋 in another; CR-239–246 are 🔲 and ✅ simultaneously). A machine cannot read the state, and neither can a new agent.

### B-8 · P2 PROCESS · Register gaps
CR-1…CR-23 and CR-117…CR-123 exist in code/docs but not in the register. CR numbering has 30 gaps in 24–264.

### B-9 · P2 HYGIENE · `.env` files not git-ignored
`backend/.env` (contains live tokens) shows as untracked, not ignored. One `git add .` away from leaking secrets.
